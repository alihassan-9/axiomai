Axiom AI — Data & Knowledge Base Sources
========================================

1. DEMO DATASET (generated, synthetic — no real/PII data)
   Location: backend/demo_data/
   Generator: backend/scripts/generate_demo_data.py
   Contents:
     Invoices (PDF):
       - clean_invoice.pdf            (arithmetic correct, policy compliant)
       - overcharge_invoice.pdf       (line total inflated by $45.00)
       - tax_error_invoice.pdf        (tax computed at the wrong rate, +$8.74)
       - policy_violation_invoice.pdf (software line over the $500 cap)
       - messy_invoice.pdf            (free-text layout; exercises LLM extraction)
     Policy documents (PDF, the RAG knowledge base):
       - expense_policy.pdf           (software cap, meal cap, hardware PO, per-diem, etc.)
       - vendor_policy.pdf            (approved vendors, NET terms, dual-approval threshold)

2. USER-PROVIDED DATA (at runtime)
   Invoices and policy PDFs uploaded by each organisation through the app UI.
   Stored in object storage (MinIO/S3); policy text is chunked + embedded into a
   per-organisation FAISS index for RAG.

3. MODELS (not data, but external artifacts pulled at runtime)
   - LLM:        Llama 3.1            via Ollama (https://ollama.com/library/llama3.1)
   - Embeddings: bge-m3               via Ollama (https://ollama.com/library/bge-m3)

NOTE: All demo data is synthetic and generated by the script above — there is no
external/scraped dataset, no survey data, and no personal data.
